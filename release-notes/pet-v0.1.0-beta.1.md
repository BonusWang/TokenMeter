更新类型：功能新增、Bug 修复、功能优化与文档更新（预发布体验版）

这是 TokenMeter 独立桌宠扩展的首个公开体验版，不替代主程序稳定版 Latest。需要主程序 `1.14.0-beta.1` 或更新兼容版本，平台为 Windows x64，通信协议为 `1`。

### 新增

- 集成 VPet 默认角色与核心互动，支持触摸头部和身体、拖动、提起、缩放、左右贴边、自主移动及待机动作；右键可打开用量面板、设置、暂停自主活动或退出。
- 新增额度云朵气泡：贴边时默认显示，离开贴边默认隐藏，也可在右键菜单手动切换；双击打开原有面板，单击不抢焦点。
- 气泡以百分比和液体水位显示剩余额度，余额账户显示金额；同步主题颜色和 DeepSeek 峰谷提示色，空闲后淡化，隐藏或拖动时暂停动画。

### 修复与优化

- 处理不同缩放、屏幕边界和负坐标显示器上的拖动、贴边、气泡避让与定位；手动显隐选择在当前贴边状态内保持。
- 移除底部工具栏、投喂、睡眠、工作、学习、游戏、金币、等级及其他养成入口和无用动画，不包含 Steam、联机、创意工坊或照片图库。
- 内置 .NET 8 运行时，无需用户另外安装；偏好与缓存独立保存，只通过本机父子进程管道接收用量展示字段。
- 核心源码随仓库维护，动画来自固定上游提交；扩展具有独立版本清单、ZIP、SHA256 校验与发布流程。

### 验证

- 宿主编译和独立 ZIP 构建成功，内置 .NET 8.0.30 运行时；NuGet 直接和间接依赖审计未发现已知漏洞。
- 真实桌宠加载 263 组动画，157 项自检全部通过，覆盖拖动、贴边、气泡交互、主题、额度展示与生命周期。
- 真实 ZIP 的 SHA256、清单、来源声明、安装、主面板桥接、更新替换、卸载和数据保留验证通过。
- 最终主程序构建环境全量回归通过：595 项通过、3 项跳过，另有 28 项子测试通过。

### 安装、兼容与校验

- 先安装 [主程序体验版](https://github.com/zensoku142/TokenMeter/releases/tag/v1.14.0-beta.1)，再通过“设置 → 桌宠”下载扩展并手动启用；无需手动解压到主程序安装目录。
- 附件：`TokenMeter-Pet-v0.1.0-beta.1-x64.zip`、`extension.json`、`SHA256SUMS.txt`。校验文件覆盖 ZIP 和版本清单；SHA256 不等同于独立发布签名。
- 桌宠菜单目前为中文；这是预发布体验版，后续将根据实际反馈继续修复。关闭或卸载桌宠后可继续使用原有悬浮球和面板。
