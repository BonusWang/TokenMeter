更新类型：功能新增、Bug 修复、功能优化与文档更新（预发布体验版）

本版本为桌宠功能首轮公开体验版，不替代稳定版 Latest。配套桌宠扩展为 `pet-v0.1.0-beta.1`，请按需安装。

### 新增

- 新增独立的“设置 → 桌宠”页，支持下载、取消、启用、检查更新、更新和卸载 VPet 精简桌宠，并常驻显示版本与安装状态。
- 桌宠源码来自 [LorisYounger/VPet](https://github.com/LorisYounger/VPet)；设置页提供常驻来源链接，包内保留上游与依赖授权声明。
- 桌宠加载成功后替代悬浮球，保留原有用量面板、主题、账户和采集功能；支持从桌宠打开面板和设置，关闭或异常退出时恢复悬浮球。
- 主程序和桌宠分别编号、打包和发布。主安装包不包含桌宠动画或 .NET 运行时，桌宠通过独立扩展按需下载；体验版可发现兼容的预发布扩展，稳定版仍只选择稳定包。

### 修复

- 安装与更新校验 SHA256、版本清单、平台和协议，阻止不安全压缩路径、版本降级及半安装状态；替换失败或中断时恢复旧包。
- 为 Windows 扫描运行时 DLL 导致的短暂占用保留最长 10 秒的有限重试；持续占用仍会回滚并提示失败。
- 隔离主题参数测试的语言初始化，修复英文 CI 环境中语言状态泄漏导致的后续断言失败；不改变应用跟随系统语言的行为。
- 未安装或资源不完整时禁用桌宠开关，避免把本地开发构建误认为已安装扩展；更新期间暂停宿主，卸载保留账户、用量和桌宠偏好。
- 隔离打包环境中的同名 ICU DLL，并在覆盖安装时清理旧试用包遗留的冲突文件；新增按真实 Qt 渲染结果及退出码判断的启动自检。

### 优化

- 桌宠只接收本机管道中的展示数据，不接收 API Key、Cookie 或登录信息；主程序退出时同步结束宿主。
- 补齐桌宠设置页的五语文案、生命周期测试、打包校验和独立发布流程。桌宠自身的原生菜单目前仍为中文。
- 本批次包含稳定版发布后已提交的主题色同步修复，以及 Codex 悬浮球液体物理效果回退。
- 清理自动化测试遗留的 Qt 窗口和定时器，避免主题与语言刷新反复处理历史控件；CI 输出慢测试耗时，不删减测试或改变业务行为。
- 将构建环境的 setuptools 最低版本提高到已修复漏洞的版本，避免旧构建依赖进入发布包。

### 验证

- 最终构建环境全量回归通过：595 项通过、3 项跳过，另有 28 项子测试通过，用时 47.30 秒。
- 修复 CI 语言隔离后，模拟英文系统环境再次全量通过：595 项通过、3 项跳过、28 项子测试通过，用时 27.43 秒。
- 桌宠真实宿主加载 263 组动画，157 项交互自检全部通过；真实 ZIP 的安装、主面板桥接、更新替换、卸载和数据保留验证通过。
- 来源链接的语言切换与布局测试、Ruff、Pyright 和 Python 依赖审计通过。
- 自有代码的 Git 空白检查通过；导入的 VPet 文件与固定上游版本逐文件一致，保留上游原有格式。
- 主安装包完成本地构建及 Qt 渲染启动自检；发布工作流还会验证首次安装、覆盖安装和数据保留。

### 安装与校验

- 下载 `TokenMeter-Setup-v1.14.0-beta.1-x64.exe` 安装体验版；同页 `SHA256SUMS.txt` 可校验完整性。
- 打开“设置 → 桌宠”，下载扩展后手动启用；扩展详情与授权见 [桌宠体验版](https://github.com/zensoku142/TokenMeter/releases/tag/pet-v0.1.0-beta.1)。
- 本轮为 Windows x64 预发布体验版，建议先备份现有数据。SHA256 不等同于独立发布签名。
