更新类型：功能新增

### 新功能

- 新增智谱 GLM Coding Plan 额度监控：5 小时 / 每周双窗口，兼容老版 `TOKENS_LIMIT` 与新版积分制 `CREDIT_LIMIT` 两种套餐响应（裸 token 鉴权，`open.bigmodel.cn` / `api.z.ai` 双站）。
- 新增 MiniMax Coding Plan 额度监控：5 小时 / 每周双窗口（Bearer 鉴权，仅统计 general 模型行，周限额仅在 `current_weekly_status==1` 时展示）。
- 多账号模型：同一厂商可导入多个账号（`ZHIPU_ACCOUNTS` / `MINIMAX_ACCOUNTS` + 下标凭据键），旧单账号配置自动迁移；凭据全部存 Windows 凭据管理器，配置文件不含明文。
- 悬浮窗改版：多账号模式下以分组悬浮卡片替换悬浮球，按厂商分组（如"Zhipu GLM · 4 账号"）聚合展示 5 小时 / 每周平均剩余进度条，低水位红色预警，悬停查看各账号明细。
- 新增 CCSwitch 凭据导入脚本 `scripts/import_ccswitch_plans.py`：只读读取 CCSwitch 数据库，按域名路由导入全部账号，支持 `--dry-run` 与重复执行（按 label 覆盖、不产生重复账号），日志全程打码。
- 聚合层 `fetch_all_accounts`：并发抓取、单账号失败隔离（错误以独立错误卡片呈现，不阻塞其他账号）。
- 面板多账号视图：账号卡片流（套餐徽章、剩余百分比、重置倒计时/日期、进度条），移除单平台用量图表区。

### 修复

- 账号列表缩短后，超出新长度的旧下标凭据残留在 Windows 凭据管理器（保存时强制清理，支持回滚）。
- 白名单模式下从设置页返回主面板时，旧的"快速切换数据平台"下拉复活的问题。
