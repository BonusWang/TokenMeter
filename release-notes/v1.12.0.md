更新类型：功能更新

### 新增

- 新增开机自启配置，可在设置中直接启用或关闭。
- 新增多 Provider 后台采集，当前面板切换平台时仍会按计划更新其他已配置平台的数据。
- 新增主题调色盘、强调色和面板透明度配置，悬浮球、图表与面板会同步应用外观设置。
- 新增悬浮球缩放配置，并优化贴边后的可见范围与拖动交互。

### 优化

- 优化 Codex 水球的自主流动、静止行进波与高水位动画，使不同额度水位下的状态更清晰。
- 重组配置、核心元数据、数据目录、更新器及打包资源，减少兼容入口中的重复实现并补充项目结构文档。

### 修复

- 修复 Codex 官方统计同步、小时级缓存和离线回退，断网或接口异常时按匿名账号指纹恢复最后成功数据。
- 修复 Codex 近 7 天统计在官方数据缺少当天记录时的展示：仅当天使用本机会话估算，后续由官方数据替换。
- 修复后台刷新与当前面板切换之间的状态竞争，避免不同 Provider 的结果互相覆盖。

### 兼容

- 保留旧版应用数据目录、凭据、单实例标识和兼容导入入口，升级后无需迁移现有配置。
- 不改变 DeepSeek、Xiaomi MiMo 的登录方式、历史数据结构和自动更新协议。

### 验证

- 完整自动化测试通过。
- Ruff 静态检查、Python 编译检查与 `git diff --check` 通过。
- GitHub Actions 将再次执行测试、依赖审计、安装包构建、覆盖安装与启动冒烟验证。

### 安装与校验

- 从本 Release 下载 `TokenMeter-Setup-v1.12.0-x64.exe`。
- 可使用同页 `SHA256SUMS.txt` 校验安装包完整性；SHA256 不等同于独立发布签名。
