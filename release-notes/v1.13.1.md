更新类型：Bug 修复

### 修复

- 修复 Windows 开机自启可能被系统启动管理移走或禁用的问题，改用当前用户启动文件夹快捷方式，并在启动和保存设置时重新对账。
- 修复旧版注册表启动项可能造成重复启动的问题，升级后会在新启动方式生效时清理旧项。
- 修复后台数据源配置校验中的类型检查错误，不改变已有配置结构和运行行为。

### 优化

- 优化 Codex 水球静止动画，剩余额度越少时液面波幅和流速越明显，额度为 0% 时完全停止流动。
- 更新 PyInstaller 与 Ruff 的补丁版本约束，继续使用现有依赖范围和构建流程。

### 验证

- 完整自动化测试通过。
- Codex 水球、开机自启、配置校验和安装器相关测试通过。
- `git diff --check` 通过；GitHub Actions 将再次执行测试、依赖审计、安装包构建、覆盖安装与启动冒烟验证。

### 安装与校验

- 从本 Release 下载 `TokenMeter-Setup-v1.13.1-x64.exe`。
- 可使用同页 `SHA256SUMS.txt` 校验安装包完整性；SHA256 不等同于独立发布签名。
