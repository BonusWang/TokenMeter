更新类型：功能新增、Bug 修复、功能优化与文档更新

### 新增

- 支持简体中文、繁体中文、英文、日文和韩文界面，可即时切换或跟随系统语言，并独立保存语言偏好。
- 支持拖动主面板左右边缘调整宽度，自动记住调整结果，并在收起、重新展开和重启后恢复。

### 修复

- 修复自定义主题色板退出后丢失的问题；即使取消本次主题色选择，也会保留已加入色板的颜色。
- 修复设置页失焦收起时未及时保存的问题，保存后返回数据页并收回悬浮球；退出程序后不再意外重新显示悬浮球。

### 优化

- 设置页整合到主面板，按六个分类组织内容，优化页签、开关与控件布局，并支持自动保存及保存状态提示。
- 界面切换语言时同步更新动态提示、图表、统计单位和 Qt 标准对话框，保留未提交的设置草稿及当前图表状态。
- 优化 Codex 悬浮球的液体物理效果，波浪、气泡与高光会随额度和状态更自然地变化。
- 优化悬浮球的静止、刷新与状态过渡表现，并保持现有交互和数据源行为不变。
- 同步更新 PySide6、PyInstaller 与 Ruff 依赖约束，发布包包含所需的 Qt 翻译资源。
- 清理仓库中已完成任务的过程文档与大型参考图，精简项目文档结构。

### 验证

- 多语言切换、设置自动保存、自定义色板持久化、面板宽度调整及 Codex 悬浮球动画相关测试通过。
- 完整自动化测试通过：495 项通过、3 项跳过，另有 25 项子测试通过。
- Ruff 静态检查与 Pyright 类型检查通过。

- `git diff --check` 通过；GitHub Actions 将再次执行测试、依赖审计、安装包构建、覆盖安装与启动冒烟验证。

- 从本 Release 下载 `TokenMeter-Setup-v1.13.2-x64.exe`。
